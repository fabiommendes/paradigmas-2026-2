## Ementa

* Programação Lógica com Prolog.
  * Problemas com restrições.
  * Backtracking e modelos de busca.
  * Integração com outras linguagens.
  * Prolog na resolução de jogos e outros problemas de decisão.
* Programação Funcional com Elm.
  * Programação funcional pura.
  * Funções de ordem superior.
  * Imutabilidade e recursão.
  * Tipos algébricos e polimorfismo paramétrico.
  * Arquitetura TEA.
* Criação de sistemas nos paradigmas de programação Lógica e Funcional.

## Critérios de avaliação

A avaliação será feita com base nas atividades:

* 1 prova de programação lógica/Prolog: 13% da nota.
* 1 prova de programação funcional/Elm: 20% da nota.
* Trabalho em grupo de (entre 5 e 7 alunos): 34% da nota.
* Testes e exercícios em sala de aula, inclusive atividades competitivas: 33% da nota.

A prova substitutiva pode ser realizada por alunos que tiverem alguma
justificativa de falta em qualquer uma das duas provas. Alunos com atestados
médicos longos também podem fazer a prova substitutiva para substituir a nota de
exercícios em sala que não puderam ser realizados.


### Código de ética e conduta

Algumas avaliações serão realizadas com auxílio do computador. Todas as
submissões serão processadas por um programa de detecção de plágio. Qualquer
atividade onde for detectada a presença de plágio será anulada sem a
possibilidade de substituição. Não será feita qualquer distinção entre o aluno
que forneceu a resposta para cópia e o aluno que obteve a mesma.


## Prepare-se

O curso utiliza alguns pacotes e ferramentas para os quais cada estudante deverá
providenciar a instalação o mais cedo o possível. Utilizaremos o ELM 0.19.2 e
o SWI-Prolog. 

O curso usa Python de forma auxiliar para implementar scripts de correção e 
ferramentas de apoio. ELM é uma linguagem de programação WEB e portanto algumas
ferramentas de JavaScript também serão utilizadas.

* uv (https://docs.astral.sh/uv/): Gestão de projetos/ambientes Python.
* pnpm (https://pnpm.io/): Gerenciador de pacotes para JavaScript. Usamos para
  instalar o Elm e ferramentas correlatas. Você pode usar outro gerenciador de
  pacotes como npm, yarn, etc.
* SWI-Prolog (https://www.swi-prolog.org/): Interpretador de Prolog. Normalmente
  está disponível nos repositórios de pacotes da sua distribuição Linux.
  Precisamos de uma versão relativamente recente (>= 9.1.12) para suportar a
  integração com o Python.
