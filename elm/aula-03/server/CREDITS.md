# Créditos dos temas

- Tema `animals`: imagens geradas por IA em `cards/animals/`; veja o
  `CREDITS.md` da pasta.
- Tema `pokemon`: as imagens não ficam neste repositório. A API devolve URLs
  da arte oficial no repositório de sprites do PokéAPI
  (https://github.com/PokeAPI/sprites). Pokémon e as artes são marcas e
  propriedade da Nintendo, Game Freak e The Pokémon Company; o uso aqui é
  apenas didático.
- Tema `simpsons`: também só URLs externas. A carta 1 de cada personagem vem
  do CDN da The Simpsons API (cdn.thesimpsonsapi.com, projeto de fãs) e a
  carta 2 das imagens de uso justo da Wikipedia em inglês (exceto Ned
  Flanders, invertido). Os Simpsons são © 20th Television/Disney; uso
  apenas didático. A Wikimedia limita requisições em sequência (HTTP 429).
